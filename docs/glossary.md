# Glossary

| Term | Meaning |
|---|---|
| **Association** | A statistical relation between two questions (for example satisfaction and use of a tool), tested with a test that suits their measurement level. |
| **Base (n)** | The respondents a figure refers to: those who answered the question in the current selection. |
| **Benjamini-Hochberg correction** | A correction of p-values when many tests are made at once; it keeps the expected share of false findings among all reported findings (false discovery rate) below the significance level. |
| **Bottom box / top box** | Share of the answers in the lowest / highest points of an ordered scale. |
| **Bucketing** | How the answers of a question become the groups of a segmentation dimension: identity, value mapping or numeric buckets. |
| **Cluster** | A topic of open answers, with a name, a description and examples, formed by the language model. |
| **Complete export** | The Word report of the Export tab with the charts by group for every dimension. |
| **Constant sum** | A number matrix whose fields should add up to a fixed total (for example 100 %). |
| **Cross filter** | A combination of two or more dimensions (for example role × site). |
| **Dimension** | A way of grouping the respondents (for example role, age group). |
| **Evasive answer** | "Don't know", "no answer" and similar; left out of scale metrics and tests. |
| **Finding** | A tested group difference that is significant, has at least a weak effect and a large enough difference in shares; reported with its facts. |
| **Item extraction** | Splitting open answers into items before clustering. |
| **Item** | A single thing named in an open answer; an answer can contain several items. |
| **Named scale** | A scale or order defined once under `settings.scales` and used by several questions or dimensions. |
| **Net Promoter Score (NPS)** | Share of promoters (9–10) minus share of detractors (0–6) of a 0–10 question. |
| **Output language** | A language the reports, the dashboard and the labels are produced in. |
| **Percentage point** | The unit of a difference between two shares: 36 % against 30 % is a difference of 6 percentage points. |
| **Pipeline report** | The Word report per output language that the pipeline and the re-export write. |
| **Pipeline** | The run of all steps from translation to the exports. |
| **Polarity** | Whether a point of a scale is positive, neutral or negative; decides the colours. |
| **Re-export** | Writing the reports and the dashboard data again after Workbench changes: with the corrected clusters, new tests of the group differences and associations, and the summaries from the cache. The clusters of the questions are kept; segment-specific clusters are formed again. |
| **Segment** | A group of respondents within a dimension (for example "students"). |
| **Segment-specific clusters** | Clusters formed from the open answers of one group only. |
| **Snapshot** | A copy of `questions.yaml` kept before every write. |
| **Source language** | The language of the answers and of the configuration (German or English). |
| **Structure file** | The export of a questionnaire from the survey tool (LimeSurvey `.lss`, Qualtrics `.qsf`); with SPSS, the `.sav` file carries data and structure. |
| **Summary schema** | The sections of the summary of a question (by default description, interpretation, group differences). |
| **Theme** | A group of questions across the questionnaire. |
| **Translation memory** | Stored translations, reused before the language model is asked again. |
| **Workbench** | The tab for manual corrections of clusters, items and numeric answers. |
