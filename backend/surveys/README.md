# Surveys

One directory per survey: `survey.yaml` and `questions.yaml` (required),
`documents.yaml` and `diagram_labels.yaml` (optional), `snapshots/` (written by the
suite). The two example surveys `ai_in_higher_education_de` and
`ai_in_higher_education_en` are generated by `examples/generate.py`.

See [docs/configuration.md](../../docs/configuration.md).
